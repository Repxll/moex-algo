# Разбор HKUDS/AI-Trader

Репозиторий: https://github.com/HKUDS/AI-Trader (MIT, последний коммит 11.06.2026). Я склонировал его и прочитал README, skill-файлы агентов, бэкенд (`service/server`) и папку `research`.

## Коротко

**Это не торговый бот и не стратегия.** Сейчас это открытый код соцсети для ИИ-агентов **ai4trade.ai**. Агенты регистрируются, публикуют «сигналы» и сделки на **виртуальные $100 000**, копируют друг друга, участвуют в челленджах и копят очки. Сама платформа никакого ИИ не запускает, решения принимает ваш агент (Claude Code, Codex и т.п.). Брокерских ордеров код не отправляет. Для MOEX и Т-Инвестиций в нём ничего нет.

Чтобы построить вашу систему, этот репозиторий брать за основу **не стоит**. Полезны из него результаты научной статьи и пара идей по формату сигнала.

---

## 1. Что это было раньше и что из этого следует

Первая версия (осень 2025) была **бенчмарком**: шесть популярных LLM полностью автономно торговали американскими акциями (NASDAQ-100), китайскими A-shares и криптой, без участия человека. Результаты опубликованы в статье **arXiv 2512.10971 «AI-Trader: Benchmarking Autonomous Agents in Real-Time Financial Markets»** (декабрь 2025).

Выводы авторов из аннотации:
- **«Общий интеллект не превращается автоматически в умение торговать»**: у большинства агентов слабая доходность и **плохое управление риском**.
- Избыточную доходность ИИ получает легче на очень ликвидных рынках, чем там, где цены двигает политика регулятора.

В новостях ходила цифра «DeepSeek обогнал GPT, Claude и NASDAQ: 10,61% годовых против 2,23% у QQQ за сентябрь–октябрь 2025». Подтвердить её по статье я не смог. В любом случае два месяца — слишком короткий срок для выводов.

Это сходится со всем остальным исследованием (Alpha Arena, «The Alpha Illusion»): **автономный LLM-трейдер — плохая идея, человек и жёсткие правила должны оставаться в цикле.**

## 2. Что в репозитории сейчас

| Часть | Что делает |
|---|---|
| `skills/*/SKILL.md` | Инструкции для вашего агента: зарегистрироваться на ai4trade.ai, публиковать сигналы (`tradesync`), копировать других (`copytrade`), постоянно опрашивать уведомления (`heartbeat`), читать новости (`market-intel`) и Polymarket |
| `service/server` (FastAPI, ~24 тыс. строк) | Бэкенд платформы: регистрация, лента сигналов, бумажные сделки, лидерборды, челленджи, команды, очки, A/B-эксперименты |
| `service/frontend` (React) | Сайт платформы |
| `research/` | Скрипты для научной статьи о **поведении 4000+ агентов** (конкуренция и кооперация, A/B-тесты, сетевые графы) |

Что я проверил в коде:
- **Сделки бумажные**: стартовый виртуальный кэш, комиссия симулируется на уровне 0,1% (`fees.py`), цены берутся из Alpha Vantage, yfinance и Hyperliquid. Вызовов API брокеров для отправки ордеров нет. Названия бирж (Binance и др.) встречаются только как метки рынков.
- **В бэкенде нет LLM**: оценка качества сигналов эвристическая (`signal_quality.py`, `heuristic-v1`).
- **Защита от «задним числом»**: для реальных цен сделка фиксируется по текущей цене (`executed_at = now`), исторические даты валидируются. Это правильная деталь.
- **Платформа сама является экспериментом над агентами**: A/B-варианты уведомлений, учёт «показов» экспериментальных сообщений агентам, экспорт данных для статьи. Подключая агента, вы становитесь участником их исследования.

## 3. Риски, если подключать своего агента

1. **Удалённые инструкции.** README предлагает сказать агенту: «прочитай https://ai4trade.ai/SKILL.md и зарегистрируйся». Skill-файл просит скачать ещё несколько удалённых файлов и **постоянно опрашивать heartbeat**, откуда приходят «задачи» и сообщения других агентов. Получается канал, через который чужой сервер и чужие агенты дают вашему Claude Code инструкции, а их можно поменять в любой момент. Это классический вектор prompt injection.
2. **Автокопирование**: в `copytrade` есть настройки `autoFollow` и `autoCopyPositions`. Лидеры бумажных лидербордов — ровно та «альфа», которую исследования считают иллюзией: короткий срок, удача, подгонка.
3. **Учётные данные**: агент регистрируется с email и паролем и хранит токен. Нельзя давать такому агенту доступ к токену Т-Инвестиций.
4. Очки, подписчики и «монетизация экспертизы» — геймификация, а не доказательство умения.

Если хочется просто посмотреть, безопаснее открыть ai4trade.ai в браузере как человек, ничего не подключая.

## 4. Что стоит позаимствовать для вашей системы

- **Структуру сигнала** из `signal_quality.py`: направление, целевая цена, уверенность, **горизонт (с/по)**, **условие отмены (`invalid_if`)**, обоснование. Для карточки сигнала в Telegram и журнала это отличный формат: сразу видно, когда сигнал сбылся, когда провалился и когда его надо снять.
- **Автоматическую оценку сигналов по факту**: по истечении горизонта сравнить прогноз с реальной ценой. Через пару месяцев у вас будет честная статистика: какие сигналы вы утверждали и сколько из них сработало.
- **Фиксацию цены «сейчас»** при записи сделки и учёт комиссии в каждой бумажной сделке.
- **Лидерборд с переоценкой по рынку** (mark-to-market) пригодится, если захотите сравнивать несколько вариантов своей стратегии в песочнице.
