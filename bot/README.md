# Бот стратегии №60 «Дивидендный разгон»

Каждый будний день в 10:05 по Москве бот проверяет бумаги индекса Мосбиржи и присылает сигналы в Telegram с кнопками ✅/❌. Одобренные заявки исполняет **только в песочнице** T-Invest: реальная торговля не подключена. Все события пишутся в `bot/journal.csv`.

Правила (проверены в `results/DIV_RUNUP_CHECK.md`):
- бумага в индексе, совет директоров рекомендовал дивиденд, дивидендная доходность ≥ 7%;
- покупка, когда до последнего дня с дивидендом осталось 3–20 торговых дней;
- продажа в последний день с дивидендом (сам дивиденд не получаем);
- до 3 позиций, по трети счёта каждая.

## Настройка
По умолчанию бот берёт токены из `~/moex_signals/.env`: тот же Telegram-бот и тот же токен песочницы, что у старой системы сигналов. Для стратегии №60 он открывает **отдельный счёт в песочнице на 10 000 ₽** и хранит его номер в `bot/state.json`. Старый `bot.py` из `~/moex_signals` должен оставаться выключенным: два процесса не могут одновременно читать сообщения одного Telegram-бота.

Если нужны свои токены, создайте `bot/.env` по инструкции ниже: он важнее старого файла.

### Свои токены (необязательно)
1. **Токен T-Invest:** в приложении Т-Инвестиций откройте Настройки → Токены T-Invest API и создайте токен для песочницы (sandbox). Токен вводите сами, в чат его не присылайте.
2. **Бот в Telegram:** напишите @BotFather → `/newbot` → получите токен бота. Затем напишите своему боту что угодно и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`: в ответе найдите `chat.id`.
3. Создайте файл `bot/.env`:
   ```
   TINVEST_TOKEN=...
   TELEGRAM_TOKEN=...
   TELEGRAM_CHAT_ID=...
   ```
4. Запуск (терминал должен оставаться открытым):
   ```
   python3 -m bot.main
   ```
   При первом запуске бот откроет счёт в песочнице и положит на него 10 000 ₽.

## Команды
- `/scan` — проверить сигналы прямо сейчас;
- `/status` — стоимость счёта и позиции.

## Ограничения
- Праздники при подсчёте торговых дней не учитываются: окно может сместиться на 1–2 дня.
- Если у дивиденда ещё нет даты объявления, бот считает, что рекомендация уже вышла. На dohod.ru такие дивиденды стоят без пометки «прогноз».
- Заявки рыночные. Отмену дивиденда собранием бот не отслеживает: если такое случилось, решение принимаете вы.
